# 꾸준히 학습지

[공식 학습지 자료실](https://zxc3285123-web.github.io/kkujunhi-worksheets/) · [교사 공유 게시판](https://zxc3285123-web.github.io/kkujunhi-worksheets/community.html)

특수교육 수업용 국어·수학·일상생활 PDF를 학년군별로 내려받을 수 있습니다. 단원과 파트 번호는 꾸준히 학습지의 편집 순서입니다.

## 공식 학습지 등록과 삭제

[공식 자료 관리](https://kkujunhi-materials-manager.zxc3285.chatgpt.site/)에서 자료실 소유자의 ChatGPT 계정으로 로그인합니다. 학년군과 교과를 선택하고 새 PDF를 게시하거나 목록에서 자료를 삭제할 수 있습니다.

## 교사 공유 게시판

1. **공유 자료 올리기**에서 제목·교과·학년군·소개를 작성하세요.
2. **GitHub에서 PDF 첨부하기**를 누른 뒤 GitHub에 로그인합니다. 글의 **PDF 첨부** 아래에 파일 한 개를 끌어다 놓고 **Create**를 누릅니다. 학생 개인정보를 제거하고 공유 권한이 있는 자료만 제출하세요.
3. 관리자 검토 후 **published** 라벨을 붙이면 게시판에 표시됩니다. 숨기려면 이 라벨을 제거합니다. GitHub에 제출한 글과 첨부는 공개됩니다.

- 학습지와 미리보기 속 그림은 [OpenMoji](https://openmoji.org/)의 아이콘을 사용했습니다. OpenMoji 그림은 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)으로 제공되며 일부 파일을 래스터 이미지로 변환해 배치했습니다.
- 학습지 글꼴은 [나눔스퀘어라운드](https://hangeul.naver.com/font)와 [주아체](https://github.com/google/fonts/tree/main/ofl/jua)를 사용했습니다.
