토큰 설정 방법
  1. 토큰 이름을 ‘꾸준히 학습지’로 정하고 만료일을 선택하세요.
  2. Repository access에서 Only select repositories를 선택하고 kkujunhi-worksheets만 선택하세요.
  3. Permissions에서 Contents에 Read and write를 지정하고 Generate token을 누르세요.
  4. 발급된 토큰을 위 입력칸에 붙여넣으세요. 토큰은 이 화면을 닫으면 다시 입력해야 합니다.
