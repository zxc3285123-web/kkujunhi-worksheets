# 공식 학습지 관리

이 폴더의 PDF가 꾸준히 학습지 자료실에 올라갑니다. 저장소 쓰기 권한이 있는 계정만 관리할 수 있습니다.

## 올리기

1. PDF 이름을 `학년군__교과__제목.pdf` 형식으로 바꿉니다. 구분 기호는 밑줄 두 개입니다.
2. 이 폴더에서 **Add file → Upload files**를 눌러 PDF를 선택한 뒤 **Commit changes**를 누릅니다.
3. GitHub Pages 배포가 끝나면 [공식 학습지 자료실](https://zxc3285123-web.github.io/kkujunhi-worksheets/)에 올라갑니다.

파일 이름 예시: `초등 1~2학년__수학__10 이하 물건 세기.pdf`

- 학년군: `초등 1~2학년`, `초등 3~4학년`, `초등 5~6학년`, `중등 1~3학년`, `고등 1~3학년`
- 교과: `국어`, `수학`, `일상생활`

## 내리기

이 폴더에서 PDF 파일을 열고 상단 파일 메뉴에서 **Delete file → Commit changes**를 누르면 다음 배포에서 자료실과 다운로드 주소에서 내려갑니다. 공개 저장소의 이전 커밋 및 이미 내려받은 사본에는 남을 수 있습니다.

다른 선생님들은 [교사 공유 게시판](https://zxc3285123-web.github.io/kkujunhi-worksheets/community.html)에서 자기 PDF를 공유합니다.
