사이트 이용

꾸준히 학습지의 PDF는 회원가입 없이 내려받을 수 있습니다. 사이트는 GitHub Pages에서 제공되며 GitHub는 호스팅 과정에서 접속 정보를 처리할 수 있습니다.

GitHub 개인정보 처리방침

Google AdSense 광고

공식 학습지 자료실에는 Google AdSense 광고가 표시될 수 있습니다. Google과 제3자 광고 제공업체는 이 사이트 및 다른 사이트의 이전 방문을 바탕으로 광고를 게재할 수 있습니다. 광고를 제공하고 성과를 측정하기 위해 쿠키를 저장하거나 읽을 수 있고, 웹 비콘, IP 주소 또는 브라우저 등의 식별자와 접속 정보를 처리할 수 있습니다.

  • Google 파트너 사이트의 데이터 사용
  • Google 광고 설정과 맞춤 광고 해제
  • 참여 광고 네트워크의 맞춤 광고 설정

교사 공유 게시판

공유 글과 첨부 파일은 GitHub에 공개로 제출됩니다. 게시판은 승인된 자료의 제목, 소개, 분류, 첨부 파일 링크, GitHub 사용자명을 표시합니다. 학생 또는 다른 사람의 개인정보는 게시글이나 파일에 넣지 마세요.
